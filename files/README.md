## 🚀 How to Deploy on GitHub Pages

1. Create a new GitHub repository named `yourusername.github.io` (e.g. `senayhailu.github.io`)
2. Upload ALL files in this folder to the repository root:
   - `index.html`
   - `slide1.png`
   - `slide2.png`
   - `slide3.png`
   - `slide4.png`
3. Go to **Settings → Pages → Source → Deploy from branch → main → / (root)**
4. Click Save. Your site will be live at `https://yourusername.github.io` in ~1 minute!
